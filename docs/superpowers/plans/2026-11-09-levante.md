# Levante Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que en Preparar el equipo tenga, después de cada evento, la lista de lo que fue para tacharla al levantar, marcar cuánto no volvió y terminar el levante; que a la administradora le llegue el aviso y descuente del stock lo roto o perdido, una sola vez.

**Architecture:** el mismo armado que la preparación. Una tabla nueva `Levante` (una fila por ítem, clave `productId` o `custom:<orderLineId>`) guarda lo marcado, y el evento suma `levanteAt`/`levantePorId`/`levantePorName`. El estado de cada ítem se calcula en `lib/levante.ts` (puro) cruzando lo marcado con el pedido de ahora. `lib/levante-db.ts` lee y escribe en transacciones que primero miran que el levante siga abierto; terminar es una escritura condicionada (`levanteAt: null`) que crea los avisos `LEVANTE` en la misma transacción y manda el push después; descontar marca el renglón con una escritura condicionada y mueve el stock por `moverStock` (el cuerpo de hoy de `saveStock`, sacado afuera). `app/actions/levante.ts` decide los permisos en el servidor. La pantalla es `/preparar/[eventId]/levante` (`components/Levante.tsx`, armada con las clases de Preparar) y `/preparar` suma la sección "Para levantar".

**Tech Stack:** Next.js 16.3 App Router (server actions), React 19, Prisma 7 + SQLite (`@prisma/adapter-better-sqlite3`), web-push, pruebas con `node --import tsx --test`.

**Spec:** `docs/superpowers/specs/2026-11-09-levante-design.md`. Leerla antes de empezar: este plan la implementa entera.

## Decisiones que la spec no cubría

Cada una sale de cómo funciona hoy Preparar o de una regla del repo. Están implementadas tal cual en las tareas.

1. **El cambio de pedido después de marcar.** Una marca guarda la cantidad que se mandó al marcar (`qty`). Si el pedido cambia después, la marca deja de valer y el ítem vuelve a "sin revisar" (como el `CAMBIO` de Preparar: algo cambió, hay que mirarlo). Una marca de un ítem que ya no está en el pedido no se muestra. Excepción: lo descontado del stock se muestra siempre como se marcó, porque ya movió el stock.
2. **Lo que se vio viaja con el toque.** Marcar manda la cantidad que mostraba la fila (`mandado`) y desmarcar manda los `faltan` que mostraba; si no coinciden con la base, no se escribe y vuelve "cambio" (lo mismo que `Visto` en Preparar). "Tachar todo" manda solo lo pendiente que se veía.
3. **Tocar una fila con faltante abre la hoja** (corregir o desmarcar), no la cambia de un toque: un toque suelto borraría un faltante anotado. Tocar una fila pendiente la tacha; tocar una tachada la destacha.
4. **Terminar con confirmación por número.** El botón manda cuántos quedaban sin revisar cuando se preguntó. Si cambió (otro teléfono marcó algo), no termina y vuelve el número de ahora (`confirmar`) para volver a preguntar; si el nuevo número es 0, termina sin preguntar. Con 0 sin revisar desde el principio no hay pregunta (como dice la spec).
5. **El aviso no le llega a quien terminó** (como el resto de los avisos de la app): si la administradora termina el levante ella misma, no se avisa a sí misma. Los avisos de la app se crean en la misma transacción que marca el evento como terminado; el push sale después.
6. **Texto del aviso sin pendientes ni faltantes:** "volvió todo". Con sin revisar y sin faltantes: "volvió todo lo revisado · N sin revisar"; sin nada revisado: "N sin revisar". Un solo faltante de 1: "faltó 1 X". Más de tres faltantes: los tres primeros "y N más". Sin unidades, como el ejemplo de la spec.
7. **Reabrir es de quien toca el stock** (`canEditStock`, la misma persona que recibe el aviso). Reabrir no deshace lo descontado: un renglón descontado no se puede volver a marcar ni desmarcar, ni con el levante reabierto (para corregir el stock está Inventario).
8. **Qué se puede descontar** (`bajaDe`): un suelto no (no tiene stock); un producto que hoy no es reutilizable no; un producto que nunca se contó (`stock` nulo) no, porque no hay de dónde descontar y "nunca se contó" no es cero; con stock 0 no hay nada que bajar. Si el evento llevó más de lo que hay (se completó con algo alquilado), el stock queda en 0 y el movimiento dice lo que bajó de verdad (`delta` = nuevo − anterior, como el ajuste de hoy). Lo que no se descuenta queda anotado y la pantalla dice por qué.
9. **Rotura / Pérdida es un toque, sin hoja de confirmación.** El servidor garantiza una sola baja por renglón, y un error se corrige en Inventario.
10. **"Para levantar" va arriba de la lista de Preparar**, con el evento más reciente primero: son pocos (la última semana, sin terminar) y se usan con apuro en el salón. Un evento sin nada que vuelva (sin pedido, o solo consumibles) no aparece. Con la sección a la vista, la lista de siempre lleva el título "Para preparar".
11. **La pantalla del levante** es `/preparar/[eventId]/levante`. La ve cualquiera que ve Preparar; no se limita por fecha (se llega desde la tarjeta o desde el aviso).
12. **La nota del movimiento** es "Levante de MUSEO 8/11": el día del evento en Argentina, con el formato de fechas de la app (sin ceros a la izquierda).
13. **Restaurar una versión del período** recrea los renglones sueltos con otro id; a diferencia de Preparar (`reasignarSueltos`), las marcas de levante de un suelto no se reasignan: el suelto vuelve a "sin revisar". Restaurar un período ya levantado es raro; se deja así a propósito.

```ts
// El levante de un evento, calculado. Sin base de datos.
//
// Después de cada evento hay que juntar en el salón todo lo que se llevó y
// subirlo al camión. La lista es lo que fue al evento y tiene que volver: los
// renglones del pedido de productos reutilizables y los ítems sueltos. Los
// consumibles no vuelven y no aparecen.
//
// Lo marcado (volvió todo, o faltan N) se guarda por ítem en `Levante`. El
// estado de cada ítem se calcula comparando eso con el pedido de ahora, como en
// la preparación (lib/preparacion.ts): así no puede quedar desactualizado.

import { esClave } from "@/lib/preparacion";
import { nombreDeCategoria, ordenDeCategoria } from "@/lib/categories";
import { validQuantity } from "@/lib/quantity";

export type EstadoLevante = "PENDIENTE" | "VOLVIO" | "FALTA";

/** Los dos motivos con que se da de baja lo que no volvió. Son los mismos
 *  `reason` de `StockMovement`: el historial del producto los muestra igual. */
export type MotivoBaja = "ROTURA" | "PERDIDA";

export function esMotivoBaja(x: unknown): x is MotivoBaja {
  return x === "ROTURA" || x === "PERDIDA";
}

/** "Rotura", "Pérdida". Un motivo desconocido (un dato viejo) se muestra tal cual. */
export function etiquetaDeMotivo(motivo: string): string {
  return motivo === "ROTURA" ? "Rotura" : motivo === "PERDIDA" ? "Pérdida" : motivo;
}

/** Hasta cuántos días para atrás sigue un evento en "Para levantar" si nadie
 *  termina su levante. Pasado eso ya no es una ayuda memoria: es historia. */
export const DIAS_PARA_LEVANTAR = 7;

/** ¿Este renglón del pedido tiene que volver del evento? Lo que se mandó (más
 *  de cero) de un producto reutilizable, o un ítem suelto: un suelto no dice si
 *  se consume, y es preferible que alguien lo tache a que se quede en el salón. */
export function vuelveDelEvento(l: { productId: string | null; productType: string | null; qty: number }): boolean {
  if (l.qty <= 0) return false;
  return l.productId === null || l.productType === "REUTILIZABLE";
}

/** El producto de una clave de ítem (ver `claveDeLinea`), o null si es un suelto. */
export function productoDeClave(clave: string): string | null {
  return clave.startsWith("custom:") ? null : clave;
}

/** Un renglón del pedido que vuelve, tal como está ahora. */
export type LineaLevante = {
  clave: string;
  itemName: string;
  unit: string;
  category: string;
  qty: number;
  note: string | null;
};

export type Descuento = { motivo: string; porName: string; at: Date };

/** Lo marcado de un ítem: lo que se mandó al marcar y cuántos no volvieron. */
export type Marca = {
  clave: string;
  itemName: string;
  unit: string;
  category: string;
  qty: number;
  faltan: number;
  porName: string;
  at: Date;
  descontado: Descuento | null;
};

export type ItemLevante = LineaLevante & {
  estado: EstadoLevante;
  /** Cuántos no volvieron. 0 si volvió todo o si todavía no se revisó. */
  faltan: number;
  marca: { porName: string; at: Date } | null;
  descontado: Descuento | null;
};

/**
 * El estado de cada ítem: lo que vuelve según el pedido, con lo marcado.
 *
 * Una marca vale si se hizo sobre la misma cantidad que pide el pedido ahora.
 * Si el pedido cambió después de marcar, el "faltan 2 de 40" ya no dice nada
 * sobre los 50 que figuran ahora: el ítem vuelve a quedar sin revisar.
 *
 * Lo descontado del stock es la excepción: ya movió el stock y no se deshace,
 * así que se muestra siempre como se marcó, aunque el renglón haya cambiado o
 * ya no esté. Una marca sin descontar de un ítem que ya no está en el pedido no
 * se muestra: la lista es lo que fue al evento.
 */
export function itemsDeLevante(lineas: LineaLevante[], marcas: Marca[]): ItemLevante[] {
  const porClave = new Map(marcas.map((m) => [m.clave, m]));
  const enPedido = new Set<string>();
  const items: ItemLevante[] = [];
  const deMarca = (m: Marca, note: string | null): ItemLevante => ({
    clave: m.clave,
    itemName: m.itemName,
    unit: m.unit,
    category: m.category,
    qty: m.qty,
    note,
    estado: m.faltan > 0 ? "FALTA" : "VOLVIO",
    faltan: m.faltan,
    marca: { porName: m.porName, at: m.at },
    descontado: m.descontado,
  });

  for (const l of lineas) {
    enPedido.add(l.clave);
    const m = porClave.get(l.clave);
    if (m && (m.descontado || m.qty === l.qty)) items.push(deMarca(m, l.note));
    else items.push({ ...l, estado: "PENDIENTE", faltan: 0, marca: null, descontado: null });
  }
  for (const m of marcas) {
    if (!enPedido.has(m.clave) && m.descontado) items.push(deMarca(m, null));
  }
  return items;
}

/** Por sector y, dentro del sector, por nombre. Es el orden en que llegan a la
 *  pantalla; `seccionesDeLevante` después sube lo pendiente. */
export function ordenarLevante<T extends { category: string; itemName: string }>(items: T[]): T[] {
  return items.sort(
    (a, b) => ordenDeCategoria(a.category) - ordenDeCategoria(b.category) || a.itemName.localeCompare(b.itemName, "es"),
  );
}

/** Un sector tal como lo dibuja la pantalla del levante. */
export type SectorDeLevante<T> = {
  category: string;
  label: string;
  total: number;
  /** Lo revisado: volvió todo o faltan. */
  marcados: number;
  pendientes: number;
  /** Lo pendiente arriba y lo revisado abajo, cada parte en el orden en que llegó. */
  filas: T[];
};

/**
 * Cómo se reparten los ítems en la pantalla: un bloque por sector, con lo
 * pendiente arriba. Lo que se marca baja al final de su sector y lo que falta
 * revisar queda a mano, sin scrollear por encima de lo ya hecho.
 *
 * Los sectores salen de los ítems (como en Preparar): una categoría vieja o
 * desconocida se ve y se marca igual, al final y en orden alfabético.
 */
export function seccionesDeLevante<T extends { category: string; estado: EstadoLevante }>(items: T[]): SectorDeLevante<T>[] {
  const porSector = new Map<string, T[]>();
  for (const i of items) {
    const del = porSector.get(i.category);
    if (del) del.push(i);
    else porSector.set(i.category, [i]);
  }
  return [...porSector.entries()]
    // Comparación de texto simple, no `localeCompare`: el orden tiene que salir
    // igual en el servidor y en el navegador.
    .sort(([a], [b]) => ordenDeCategoria(a) - ordenDeCategoria(b) || (a < b ? -1 : a > b ? 1 : 0))
    .map(([category, del]) => {
      const pendientes = del.filter((i) => i.estado === "PENDIENTE");
      return {
        category,
        label: nombreDeCategoria(category),
        total: del.length,
        marcados: del.length - pendientes.length,
        pendientes: pendientes.length,
        filas: [...pendientes, ...del.filter((i) => i.estado !== "PENDIENTE")],
      };
    });
}

export type ResumenDeLevante = {
  total: number;
  marcados: number;
  sinRevisar: number;
  /** Lo que no volvió, en el orden de la lista. */
  faltantes: { itemName: string; faltan: number }[];
};

/** Las cuentas del levante: la tarjeta ("Levante · N de M"), la confirmación
 *  de terminar ("Quedan N sin revisar") y el aviso salen de acá. */
export function resumenDeLevante(items: { itemName: string; estado: EstadoLevante; faltan: number }[]): ResumenDeLevante {
  const sinRevisar = items.filter((i) => i.estado === "PENDIENTE").length;
  return {
    total: items.length,
    marcados: items.length - sinRevisar,
    sinRevisar,
    faltantes: items.filter((i) => i.estado === "FALTA").map((i) => ({ itemName: i.itemName, faltan: i.faltan })),
  };
}

/** Una fila pendiente de un sector tal como se veía al tocar "Tachar todo". */
export type VistoDeLevante = { clave: string; qty: number };

/** Lo visto de un sector entero, comprobado como cualquier dato de afuera. El
 *  tope es por si acaso: ningún sector de un pedido real llega a tanto. */
export function sonVistosDeLevante(x: unknown): x is VistoDeLevante[] {
  return (
    Array.isArray(x) &&
    x.length <= 500 &&
    x.every((fila: unknown) => {
      if (typeof fila !== "object" || fila === null) return false;
      const v = fila as Record<string, unknown>;
      return esClave(v.clave) && validQuantity(v.qty);
    })
  );
}

/** "¿Cuántos faltan?": al menos 1 (cero es "volvió todo", que es otro toque) y
 *  como mucho lo que se mandó. */
export function esFaltaValida(faltan: unknown, mandado: unknown): boolean {
  return validQuantity(mandado, 1) && validQuantity(faltan, 1) && (faltan as number) <= (mandado as number);
}

/**
 * "Tachar todo el sector" toma solo lo pendiente del sector que se vio y sigue
 * igual. Lo que entró al pedido después de dibujar la pantalla nadie lo vio,
 * así que no viene en `vistos` y queda pendiente.
 *
 * `salteados` son los vistos que no se marcan porque cambiaron (otra cantidad,
 * ya no están, otro teléfono les marcó un faltante): la pantalla avisa que hay
 * que revisarlos. Lo que otro teléfono ya marcó como "volvió todo" quedó como
 * se quería y no se cuenta.
 */
export function paraMarcarSector(
  items: ItemLevante[],
  category: string,
  vistos: VistoDeLevante[],
): { claves: string[]; salteados: number } {
  const porClave = new Map(items.map((i) => [i.clave, i]));
  const vistas = new Set<string>();
  const claves: string[] = [];
  let salteados = 0;
  for (const v of vistos) {
    if (vistas.has(v.clave)) continue;
    vistas.add(v.clave);
    const i = porClave.get(v.clave);
    const igual = i !== undefined && i.category === category && i.qty === v.qty;
    if (igual && i.estado === "PENDIENTE") claves.push(v.clave);
    else if (igual && i.estado === "VOLVIO") {
      // Ya marcado como se quería: nada que hacer ni que avisar.
    } else salteados++;
  }
  return { claves, salteados };
}
```

```ts
/** El texto de un archivo, con los fines de línea de Unix: en Windows git los

function fuente(rel: string): string {
  let dir = process.cwd();
  for (let i = 0; i < 5; i++) {
    const candidato = path.join(dir, rel);
    if (fs.existsSync(candidato)) return fs.readFileSync(candidato, "utf8").replace(/\r\n/g, "\n");
    dir = path.dirname(dir);
  }
  throw new Error(`no se encontró ${rel}`);
}

/** El cuerpo de una acción exportada: desde su `export async function` hasta la
 *  siguiente (o el final del archivo). */
function cuerpoDe(s: string, nombre: string): string {
  const desde = s.indexOf(`export async function ${nombre}`);

  const resto = s.slice(desde + 10);
  const hasta = resto.search(/^export async function /m);
  return s.slice(desde, hasta === -1 ? s.length : desde + 10 + hasta);
}
```

```ts
import { prisma } from "@/lib/db";
import { diaDe, hoy, instanteDe, sumarDias } from "@/lib/dates";
import { claveDeLinea } from "@/lib/preparacion";
import {
  DIAS_PARA_LEVANTAR,
  itemsDeLevante,
  ordenarLevante,
  paraMarcarSector,
  resumenDeLevante,
  vuelveDelEvento,
  type ItemLevante,
  type LineaLevante,
  type Marca,
  type VistoDeLevante,
} from "@/lib/levante";

// El levante contra la base: leer lo que vuelve y lo marcado, marcar y
// desmarcar. El cálculo vive en lib/levante.ts, que es puro.
//
// Toda escritura va en una transacción que primero mira que el levante siga
// abierto (evento vivo y sin terminar): terminar y marcar a la vez desde dos
// teléfonos no puede dejar una marca nueva en un levante ya avisado.

/** `prisma` o el cliente de una transacción: lo que hace falta para leer. */
export type Db = Pick<typeof prisma, "orderLine" | "levante" | "event">;

export type Actor = { id: string; name: string };

/** Un evento vivo: ni él ni su período en la papelera. */
const VIVO = { deletedAt: null, period: { deletedAt: null } };

/** Lo que vuelve del evento según su pedido de ahora, con nombre, unidad y sector. */
export async function lineasParaLevantar(db: Db, eventId: string): Promise<LineaLevante[]> {
  const lineas = await db.orderLine.findMany({
    where: { eventId },
    include: { product: { select: { name: true, unit: true, category: true, type: true } } },
  });
  return lineas
    .filter((l) => vuelveDelEvento({ productId: l.productId, productType: l.product?.type ?? null, qty: l.qty }))
    .map((l) => ({
      clave: claveDeLinea(l),
      itemName: l.product?.name ?? l.customName ?? "Ítem",
      unit: l.product?.unit ?? l.customUnit ?? "Unidad",
      category: l.product?.category ?? l.customCategory ?? "ENSERES",
      qty: l.qty,
      note: l.note,
    }));
}

async function marcasDelEvento(db: Db, eventId: string): Promise<Marca[]> {
  const filas = await db.levante.findMany({ where: { eventId } });
  return filas.map((f) => ({
    clave: f.clave,
    itemName: f.itemName,
    unit: f.unit,
    category: f.category,
    qty: f.qty,
    faltan: f.faltan,
    porName: f.porName,
    at: f.at,
    descontado: f.descontadoAt
      ? { motivo: f.descontadoMotivo ?? "", porName: f.descontadoPorName ?? "", at: f.descontadoAt }
      : null,
  }));
}

/** El estado de cada ítem del levante, ordenado por sector y por nombre. */
export async function levanteDelEvento(eventId: string, db: Db = prisma): Promise<ItemLevante[]> {
  const [lineas, marcas] = await Promise.all([lineasParaLevantar(db, eventId), marcasDelEvento(db, eventId)]);
  return ordenarLevante(itemsDeLevante(lineas, marcas));
}

/** ¿Se puede marcar? El evento sigue vivo y su levante no se terminó. */
async function abierto(db: Db, eventId: string): Promise<boolean> {
  return (await db.event.count({ where: { id: eventId, ...VIVO, levanteAt: null } })) > 0;
}

/** `cambio`: el pedido no dice lo que mostraba la fila. `cerrado`: el levante
 *  se terminó o el evento ya no está. `descontado`: ese faltante ya bajó el
 *  stock y no se toca. */
export type ResultadoMarca = "marcado" | "cambio" | "no-existe" | "cerrado" | "descontado";

/**
 * Marca un ítem con cuántos no volvieron (0 = volvió todo).
 *
 * `mandado` es la cantidad que mostraba la fila. Si el pedido cambió entre el
 * dibujo y el toque, no se marca un número que nadie vio: vuelve "cambio" y la
 * pantalla se pone al día. Nombre, unidad y sector salen del renglón de ahora.
 * El rango de `faltan` lo comprueba la acción (`esFaltaValida`).
 */
async function marcar(eventId: string, clave: string, actor: Actor, mandado: number, faltan: number): Promise<ResultadoMarca> {
  return prisma.$transaction(async (tx): Promise<ResultadoMarca> => {
    if (!(await abierto(tx, eventId))) return "cerrado";
    const linea = (await lineasParaLevantar(tx, eventId)).find((l) => l.clave === clave);
    if (!linea) return "no-existe";
    if (linea.qty !== mandado) return "cambio";
    const previa = await tx.levante.findUnique({ where: { eventId_clave: { eventId, clave } }, select: { descontadoAt: true } });
    if (previa?.descontadoAt) return "descontado";
    const datos = {
      itemName: linea.itemName,
      unit: linea.unit,
      category: linea.category,
      qty: linea.qty,
      faltan,
      porId: actor.id,
      porName: actor.name,
      at: new Date(),
    };
    await tx.levante.upsert({
      where: { eventId_clave: { eventId, clave } },
      update: datos,
      create: { eventId, clave, ...datos },
    });
    return "marcado";
  });
}

/** Volvió todo lo que se mandó de este ítem. */
export function marcarVolvio(eventId: string, clave: string, actor: Actor, mandado: number): Promise<ResultadoMarca> {
  return marcar(eventId, clave, actor, mandado, 0);
}

/** No volvieron `faltan` de los `mandado`. También corrige un faltante ya marcado. */
export function marcarFalta(eventId: string, clave: string, actor: Actor, mandado: number, faltan: number): Promise<ResultadoMarca> {
  return marcar(eventId, clave, actor, mandado, faltan);
}

/**
 * Desmarca un ítem: vuelve a quedar sin revisar. Solo si sigue como se vio
 * (`faltanVisto`): un "volvió todo" viejo en la pantalla no puede borrar el
 * "faltan 3" que otro teléfono marcó después. Lo descontado no se desmarca.
 */
export async function desmarcar(eventId: string, clave: string, faltanVisto: number): Promise<"desmarcado" | "cambio" | "cerrado"> {
  return prisma.$transaction(async (tx) => {
    if (!(await abierto(tx, eventId))) return "cerrado" as const;
    const borrada = await tx.levante.deleteMany({ where: { eventId, clave, faltan: faltanVisto, descontadoAt: null } });
    return borrada.count > 0 ? ("desmarcado" as const) : ("cambio" as const);
  });
}

/**
 * "Tachar todo el sector": marca como "volvió todo" lo pendiente del sector que
 * se vio y sigue igual (`paraMarcarSector`). Devuelve cuántos marcó este toque
 * y cuántos de los vistos salteó porque cambiaron mientras tanto.
 */
export async function marcarSector(
  eventId: string,
  category: string,
  actor: Actor,
  vistos: VistoDeLevante[],
): Promise<{ resultado: "ok" | "cerrado"; marcados: number; salteados: number }> {
  return prisma.$transaction(async (tx) => {
    if (!(await abierto(tx, eventId))) return { resultado: "cerrado" as const, marcados: 0, salteados: 0 };
    const items = await levanteDelEvento(eventId, tx);
    const { claves, salteados } = paraMarcarSector(items, category, vistos);
    const porClave = new Map(items.map((i) => [i.clave, i]));
    const at = new Date();
    for (const clave of claves) {
      const i = porClave.get(clave)!;
      const datos = { itemName: i.itemName, unit: i.unit, category: i.category, qty: i.qty, faltan: 0, porId: actor.id, porName: actor.name, at };
      // upsert y no create: un ítem pendiente puede tener una marca vieja (el
      // pedido cambió después de marcarlo), y esa se pisa con lo de ahora.
      await tx.levante.upsert({ where: { eventId_clave: { eventId, clave } }, update: datos, create: { eventId, clave, ...datos } });
    }
    return { resultado: "ok" as const, marcados: claves.length, salteados };
  });
}

export type EventoParaLevantar = {
  id: string;
  lugar: string;
  date: Date;
  dia: string;
  /** Lo revisado ("Levante · N de M"). */
  marcados: number;
  total: number;
};

/**
 * Los eventos vivos con el levante sin terminar, desde su día (en Argentina)
 * hasta `DIAS_PARA_LEVANTAR` días para atrás. El más reciente primero: es el
 * que se está levantando. Un evento sin nada que vuelva (sin pedido, o solo
 * consumibles) no tiene levante y no aparece.
 */
export async function eventosParaLevantar(hoyDia: string = hoy()): Promise<EventoParaLevantar[]> {
  const eventos = await prisma.event.findMany({
    where: {
      ...VIVO,
      levanteAt: null,
      date: { gte: instanteDe(sumarDias(hoyDia, -DIAS_PARA_LEVANTAR), "00:00"), lt: instanteDe(sumarDias(hoyDia, 1), "00:00") },
    },
    orderBy: { date: "desc" },
    select: { id: true, lugar: true, date: true },
  });
  const out: EventoParaLevantar[] = [];
  for (const e of eventos) {
    const { total, marcados } = resumenDeLevante(await levanteDelEvento(e.id));
    if (total === 0) continue;
    out.push({ ...e, dia: diaDe(e.date), marcados, total });
  }
  return out;
}
```

```ts
export type LevanteResult = { ok: boolean; error?: string; count?: number; aviso?: string; confirmar?: number };

type Guarda = { user: { id: string; name: string; role: string }; error: null } | { user: null; error: string };

/** El permiso se mira antes que la base (a quien no puede no se le dice ni si
 *  el evento existe), y solo vale sobre un evento vivo. */
async function requerirEvento(eventId: string, puede: (role: string) => boolean, sinPermiso: string): Promise<Guarda> {
  const user = await getSessionUser();
  if (!user) return { user: null, error: "Tenés que iniciar sesión." };
  if (!puede(user.role)) return { user: null, error: sinPermiso };
  if (typeof eventId !== "string" || eventId.length === 0 || eventId.length > 64) {
    return { user: null, error: "Evento inválido." };
  }
  const ev = await prisma.event.findFirst({
    where: { id: eventId, deletedAt: null, period: { deletedAt: null } },
    select: { id: true },
  });
  if (!ev) return { user: null, error: "El evento ya no está disponible." };
  return { user, error: null };
}

/** Marcar y terminar: los mismos que tildan la preparación. */
function requerirMarcar(eventId: string): Promise<Guarda> {
  return requerirEvento(eventId, canPreparar, "No tenés permiso para marcar el levante.");
}

function revalidar(eventId: string) {
  revalidatePath("/preparar");
  revalidatePath(`/preparar/${eventId}/levante`);
}

const ERROR_DE_MARCA: Record<Exclude<ResultadoMarca, "marcado">, string> = {
  cambio: "Ese ítem cambió recién: revisalo.",
  "no-existe": "Ese ítem ya no está en el pedido.",
  cerrado: "El levante ya se terminó: no se puede marcar.",
  descontado: "Ese faltante ya se descontó del stock: no se puede cambiar.",
};

function respuestaDeMarca(eventId: string, r: ResultadoMarca): LevanteResult {
  if (r !== "marcado") return { ok: false, error: ERROR_DE_MARCA[r] };
  revalidar(eventId);
  return { ok: true };
}

/** Volvió todo lo que se mandó de un ítem. `mandado` es lo que mostraba la fila. */
export async function marcarVolvioItem(eventId: string, clave: string, mandado: number): Promise<LevanteResult> {
  const { user, error } = await requerirMarcar(eventId);
  if (!user) return { ok: false, error: error! };
  if (!esClave(clave) || !validQuantity(mandado, 1)) return { ok: false, error: "Ítem inválido." };
  return respuestaDeMarca(eventId, await marcarVolvio(eventId, clave, user, mandado));
}

/** No volvieron `faltan` de los `mandado`. También corrige un faltante. */
export async function marcarFaltaItem(eventId: string, clave: string, mandado: number, faltan: number): Promise<LevanteResult> {
  const { user, error } = await requerirMarcar(eventId);
  if (!user) return { ok: false, error: error! };
  if (!esClave(clave)) return { ok: false, error: "Ítem inválido." };
  if (!esFaltaValida(faltan, mandado)) return { ok: false, error: "Elegí cuántos faltan: de 1 a lo que se mandó." };
  return respuestaDeMarca(eventId, await marcarFalta(eventId, clave, user, mandado, faltan));
}

/** Vuelve a dejar un ítem sin revisar. Solo si sigue como se vio. */
export async function desmarcarItem(eventId: string, clave: string, faltanVisto: number): Promise<LevanteResult> {
  const { user, error } = await requerirMarcar(eventId);
  if (!user) return { ok: false, error: error! };
  if (!esClave(clave) || !validQuantity(faltanVisto)) return { ok: false, error: "Ítem inválido." };
  const r = await desmarcar(eventId, clave, faltanVisto);
  if (r !== "desmarcado") return { ok: false, error: ERROR_DE_MARCA[r] };
  revalidar(eventId);
  return { ok: true };
}

/** Tacha lo pendiente de un sector que se vio y sigue igual. Lo que cambió
 *  mientras tanto no se marca, y se avisa sin frenar el resto. */
export async function marcarSectorEntero(eventId: string, category: string, vistos: VistoDeLevante[]): Promise<LevanteResult> {
  const { user, error } = await requerirMarcar(eventId);
  if (!user) return { ok: false, error: error! };
  if (!esCategoria(category)) return { ok: false, error: "Sector inválido." };
  if (!sonVistosDeLevante(vistos)) return { ok: false, error: "Ítems inválidos." };
  const { resultado, marcados, salteados } = await marcarSector(eventId, category, user, vistos);
  if (resultado === "cerrado") return { ok: false, error: ERROR_DE_MARCA.cerrado };
  revalidar(eventId);
  if (salteados === 0) return { ok: true, count: marcados };
  const aviso =
    salteados === 1
      ? "1 ítem cambió mientras tanto y no se tachó: revisalo."
      : `${salteados} ítems cambiaron mientras tanto y no se tacharon: revisalos.`;
  return { ok: true, count: marcados, aviso };
}
```

```ts
/** A dónde lleva el aviso al tocarlo, y la tarjeta de "Para levantar". */
export function linkDelLevante(eventId: string): string {
  return `/preparar/${eventId}/levante`;
}

/** Cuántos faltantes se nombran en el aviso; el resto se cuenta ("y 2 más"). */
const MAX_EN_EL_AVISO = 3;
// El lugar y el nombre de quien terminó los escribe una persona y no tienen
// tope: acotados, no se comen el detalle.
const MAX_LUGAR = 60;
const MAX_QUIEN = 60;

/** "a", "a y b", "a, b y c". */
function enLista(partes: string[]): string {
  if (partes.length <= 1) return partes.join("");
  return `${partes.slice(0, -1).join(", ")} y ${partes[partes.length - 1]}`;
}

/**
 * El aviso que le llega a quien toca el stock al terminar un levante.
 *
 * - `mensaje`, para la lista de Avisos: "Levante de MUSEO: faltaron 5 Copa vino
 *   y 2 Mantel redondo".
 * - `title` y `body`, para el push: "Levante de MUSEO" / "Faltaron 5 Copa vino
 *   y 2 Mantel redondo", firmado con quien lo terminó.
 *
 * No promete nada que no se marcó: "volvió todo" solo si se revisó todo. Si
 * quedó algo sin revisar, lo revisado que volvió es "volvió todo lo revisado"
 * y se dice cuánto quedó sin revisar.
 */
export function textoDelLevante(
  lugar: string,
  items: { itemName: string; estado: EstadoLevante; faltan: number }[],
  porName: string,
): { title: string; body: string; mensaje: string } {
  const { faltantes, sinRevisar, marcados } = resumenDeLevante(items);
  const partes: string[] = [];
  if (faltantes.length > 0) {
    const nombrados = faltantes.slice(0, MAX_EN_EL_AVISO).map((f) => `${f.faltan} ${f.itemName}`);
    const resto = faltantes.length - nombrados.length;
    const lista = resto > 0 ? `${nombrados.join(", ")} y ${resto} más` : enLista(nombrados);
    const verbo = faltantes.length === 1 && faltantes[0].faltan === 1 ? "faltó" : "faltaron";
    partes.push(`${verbo} ${lista}`);
  } else if (sinRevisar === 0) {
    partes.push("volvió todo");
  } else if (marcados > 0) {
    partes.push("volvió todo lo revisado");
  }
  if (sinRevisar > 0) partes.push(`${sinRevisar} sin revisar`);
  const detalle = partes.join(" · ");
  const titulo = `Levante de ${recortar(lugar, MAX_LUGAR)}`;
  const pie = `\n— ${recortar(porName, MAX_QUIEN)}`;
  return {
    title: titulo,
    body: recortar(detalle.charAt(0).toUpperCase() + detalle.slice(1), MAX_CUERPO - pie.length) + pie,
    mensaje: recortar(`${titulo}: ${detalle}`, MAX_CUERPO),
  };
}
```

```ts
/** `confirmar`: cambió cuántos quedan sin revisar desde que se preguntó; trae
 *  el número de ahora para volver a preguntar. `ya`: otro teléfono lo terminó. */
export type ResultadoTerminar =
  | { r: "terminado"; avisados: number }
  | { r: "confirmar"; sinRevisar: number }
  | { r: "ya" }
  | { r: "no-existe" };

/**
 * Termina el levante y le avisa a quien puede tocar el stock.
 *
 * `sinRevisarVisto` es el número que se confirmó en la pantalla ("Quedan 3 sin
 * revisar"). Si mientras tanto otro teléfono marcó o desmarcó algo, no se
 * termina: vuelve "confirmar" con el número de ahora. Lo que queda sin revisar
 * queda así, no como faltante.
 *
 * La marca del evento es condicionada (`levanteAt: null`) y los avisos de la
 * app se crean en la misma transacción: con dos teléfonos a la vez, termina y
 * avisa uno solo, y no puede quedar un levante terminado sin su aviso. El push
 * sale después, fuera de la transacción: `sendPushToUser` nunca lanza. No le
 * llega a quien lo terminó (como el resto de los avisos de la app).
 */
export async function terminarLevante(
  eventId: string,
  actor: Actor,
  sinRevisarVisto: number,
  ahora: Date = new Date(),
): Promise<ResultadoTerminar> {
  const hecho = await prisma.$transaction(async (tx) => {
    const ev = await tx.event.findFirst({ where: { id: eventId, ...VIVO }, select: { lugar: true, levanteAt: true } });
    if (!ev) return { r: "no-existe" as const };
    if (ev.levanteAt) return { r: "ya" as const };
    const items = await levanteDelEvento(eventId, tx);
    const { sinRevisar } = resumenDeLevante(items);
    if (sinRevisar !== sinRevisarVisto) return { r: "confirmar" as const, sinRevisar };
    const puesta = await tx.event.updateMany({
      where: { id: eventId, levanteAt: null },
      data: { levanteAt: ahora, levantePorId: actor.id, levantePorName: actor.name },
    });
    if (puesta.count !== 1) return { r: "ya" as const };
    const texto = textoDelLevante(ev.lugar, items, actor.name);
    const link = linkDelLevante(eventId);
    const personas = await tx.user.findMany({ where: { id: { not: actor.id } }, select: { id: true, role: true }, orderBy: { name: "asc" } });
    const avisos: { id: string; userId: string }[] = [];
    for (const u of personas.filter((p) => canEditStock(p.role))) {
      const n = await tx.notification.create({
        data: {
          recipientId: u.id,
          actorName: actor.name,
          type: "LEVANTE",
          message: texto.mensaje,
          eventId,
          linkUrl: link,
          // El push sale acá mismo: nace marcado como enviado para que ningún
          // barrido lo vuelva a mandar (como el resumen de la mañana).
          pushedAt: ahora,
        },
      });
      avisos.push({ id: n.id, userId: u.id });
    }
    return { r: "terminado" as const, texto, link, avisos };
  });
  if (hecho.r !== "terminado") return hecho;
  for (const a of hecho.avisos) {
    await sendPushToUser(
      a.userId,
      { title: hecho.texto.title, body: hecho.texto.body, url: hecho.link, tag: `levante-${eventId}` },
      { kind: "LEVANTE", notificationId: a.id },
    );
  }
  return { r: "terminado", avisados: hecho.avisos.length };
}

/**
 * Reabre un levante terminado para corregirlo: el evento vuelve a "Para
 * levantar" (si está dentro de la semana) y se puede marcar de nuevo. Lo ya
 * descontado del stock no se toca. Condicionado: con dos toques, reabre uno.
 */
export async function reabrirLevante(eventId: string): Promise<"reabierto" | "ya" | "no-existe"> {
  const ev = await prisma.event.findFirst({ where: { id: eventId, ...VIVO }, select: { id: true } });
  if (!ev) return "no-existe";
  const r = await prisma.event.updateMany({
    where: { id: eventId, levanteAt: { not: null } },
    data: { levanteAt: null, levantePorId: null, levantePorName: null },
  });
  return r.count === 1 ? "reabierto" : "ya";
}
```

```ts
  const { user, error } = await requerirMarcar(eventId);
```

```tsx
  marcarFaltaItem,
  marcarSectorEntero,
  marcarVolvioItem,
  reabrirElLevante,
  terminarElLevante,
  type LevanteResult,
} from "@/app/actions/levante";
import { intentar } from "@/lib/actualizacion";
import { esFaltaValida, resumenDeLevante, seccionesDeLevante, type EstadoLevante, type ResumenDeLevante, type VistoDeLevante } from "@/lib/levante";
import { esCategoria } from "@/lib/categories";
import { vibrar, PATRON } from "@/lib/vibrar";
import { RefrescoPeriodico } from "@/components/RefrescoPeriodico";

type Item = {
  clave: string;
  itemName: string;
  unit: string;
  category: string;
  qty: number;
  note: string | null;
  estado: EstadoLevante;
  faltan: number;
  marcadoPor: string | null;
  /** "Rotura", "Pérdida": ya se descontó del stock. */
  descontado: string | null;
};

  evento: { id: string; lugar: string; cuando: string; esHoy: boolean };
  items: Item[];
  /** Quién y cuándo lo terminó, o null si sigue abierto. */
  terminado: { por: string } | null;
  puedeMarcar: boolean;
  puedeAjustarStock: boolean;
};

const unidad = (u: string) => (u === "Unidad" ? "" : ` ${u.toLowerCase()}`);

/** Cuánto dura el error en pantalla. Sin esto se queda hasta el próximo toque. */
const ERROR_MS = 8_000;

/** La hoja "¿Cuántos faltan?", con lo que mostraba la fila al abrirla. */
type Hoja = { clave: string; itemName: string; unit: string; qty: number; estado: EstadoLevante; faltanVisto: number; valor: string };
const sigueComoSeAbrio = (h: Hoja, i: Item) =>
  h.clave === i.clave && h.qty === i.qty && h.estado === i.estado && h.faltanVisto === i.faltan;

/** "Volvieron 38", dicho al revés de lo que se elige: es lo que se ve en el salón. */
function textoDeVuelta(h: Hoja): string {
  const n = Number(h.valor);
  if (!esFaltaValida(n, h.qty)) return `De 1 a ${h.qty}`;
  const volvieron = h.qty - n;
  return volvieron === 0 ? "No volvió ninguno" : volvieron === 1 ? "Volvió 1" : `Volvieron ${volvieron}`;
}

/** El cierre en una línea: "2 ítems con faltantes · 1 sin revisar". */
function textoDeCierre(r: ResumenDeLevante): string {
  const partes: string[] = [];
  if (r.faltantes.length > 0) partes.push(r.faltantes.length === 1 ? "1 ítem con faltantes" : `${r.faltantes.length} ítems con faltantes`);
  if (r.sinRevisar > 0) partes.push(`${r.sinRevisar} sin revisar`);
  return partes.length === 0 ? "Volvió todo." : partes.join(" · ");
}

/**
 * El levante de un evento, para el teléfono de quien junta en el salón.
 *
 * La lista es lo que fue al evento, por sector, con lo pendiente arriba. Tocar
 * la fila la tacha (volvió todo); "Falta" pregunta cuántos no volvieron. Al pie,
 * "Terminar levante" le avisa a la administradora.
 */
export function Levante({ data }: { data: Data }) {
  const router = useRouter();
  // Cada fila se bloquea solo mientras se guarda ella: un toque lento no puede
  // tragarse los toques sobre las demás.
  const [enVuelo, setEnVuelo] = useState<ReadonlySet<string>>(() => new Set());
  // Un objeto y no un texto: dos errores iguales seguidos reinician el reloj.
  const [error, setError] = useState<{ texto: string } | null>(null);
  const [hoja, setHoja] = useState<Hoja | null>(null);
  // El sector a tachar entero, con sus filas pendientes tal como se veían al
  // tocar "Tachar todo": lo que entre mientras el diálogo está abierto nadie lo vio.
  const [sectorAConfirmar, setSectorAConfirmar] = useState<{ category: string; vistos: VistoDeLevante[] } | null>(null);
  // Cuántos quedaban sin revisar cuando se preguntó "¿Terminar igual?".
  const [terminarConfirmar, setTerminarConfirmar] = useState<number | null>(null);

  // El error se va solo: quien está mirando otra parte de la lista no lo va a
  // cerrar, y uno viejo en pantalla hace dudar de si lo último se guardó.
  useEffect(() => {
    if (!error) return;
    const id = setTimeout(() => setError(null), ERROR_MS);
    return () => clearTimeout(id);
  }, [error]);

  async function correr(clave: string, accion: () => Promise<LevanteResult>): Promise<LevanteResult> {
    setEnVuelo((prev) => new Set(prev).add(clave));
    const r = await intentar(accion);
    setEnVuelo((prev) => {
      const sig = new Set(prev);
      sig.delete(clave);
      return sig;
    });
    if (r.ok && !r.aviso) {
      setError(null);
      return r;
    }
    // Terminar con un número viejo no es un error: quien llama vuelve a preguntar
    // con el de ahora. Un aviso tampoco (lo demás se guardó), pero va en la tira.
    if (r.confirmar === undefined) setError({ texto: (r.ok ? r.aviso : r.error) ?? "No se pudo guardar." });
    // Si falló o hubo aviso, la pantalla quedó vieja: se vuelve a pedir. Sin señal
    // no se pide nada: `router.refresh()` falla y Next 16 hace una navegación
    // completa, que el service worker contesta con la página de "sin conexión", y
    // esa reemplazaría la lista que se está leyendo, justo donde no hay señal. La
    // franja de abajo ya avisa; al volver la señal, `SinConexion` refresca.
    if (navigator.onLine) router.refresh();
    return r;
  }

  function abrirHoja(i: Item) {
    if (!data.puedeMarcar || i.descontado !== null || enVuelo.has(i.clave)) return;
    // Propone todos (lo más común cuando se pierde algo es que no aparezca
    // ninguno), o lo ya marcado si se está corrigiendo.
    setHoja({
      clave: i.clave,
      itemName: i.itemName,
      unit: i.unit,
      qty: i.qty,
      estado: i.estado,
      faltanVisto: i.faltan,
      valor: String(i.estado === "FALTA" ? i.faltan : i.qty),
    });
  }

  /** Tocar la fila: lo pendiente pasa a "volvió todo" y lo que volvió vuelve a
   *  pendiente (errores de quien marca). Un faltante no se resuelve de un toque:
   *  abre la hoja para corregirlo o desmarcarlo. */
  function alternar(i: Item) {
    if (!data.puedeMarcar || i.descontado !== null || enVuelo.has(i.clave)) return;
    if (i.estado === "FALTA") {
      abrirHoja(i);
      return;
    }
    vibrar(i.estado === "VOLVIO" ? PATRON.destildar : PATRON.tildar);
    void correr(i.clave, () =>
      i.estado === "VOLVIO" ? desmarcarItem(data.evento.id, i.clave, 0) : marcarVolvioItem(data.evento.id, i.clave, i.qty),
    );
  }

  function pasoHoja(d: number) {
    // Updater funcional: toques rápidos seguidos se acumulan bien.
    setHoja((h) => {
      if (!h) return h;
      const n = Math.round(Number(h.valor));
      const base = Number.isFinite(n) ? n : h.qty;
      return { ...h, valor: String(Math.min(h.qty, Math.max(1, base + d))) };
    });
  }

  function guardarHoja(h: Hoja) {
    const n = Number(h.valor);
    if (!esFaltaValida(n, h.qty)) return;
    setHoja(null);
    vibrar(PATRON.tildar);
    void correr(h.clave, () => marcarFaltaItem(data.evento.id, h.clave, h.qty, n));
  }

  function desmarcarHoja(h: Hoja) {
    setHoja(null);
    vibrar(PATRON.destildar);
    void correr(h.clave, () => desmarcarItem(data.evento.id, h.clave, h.faltanVisto));
  }

  function tacharSector(a: { category: string; vistos: VistoDeLevante[] }) {
    setSectorAConfirmar(null);
    vibrar(PATRON.tildarSector);
    void correr(`sector:${a.category}`, () => marcarSectorEntero(data.evento.id, a.category, a.vistos));
  }

  async function terminar(sinRevisarVisto: number) {
    setTerminarConfirmar(null);
    const r = await correr("terminar", () => terminarElLevante(data.evento.id, sinRevisarVisto));
    if (r.confirmar === undefined) {
      if (r.ok) vibrar(PATRON.tildarSector);
      return;
    }
    // Otro teléfono marcó o desmarcó algo mientras tanto. Si ya no queda nada sin
    // revisar no hay nada que preguntar; si queda, se pregunta con el número de ahora.
    if (r.confirmar === 0) void terminar(0);
    else setTerminarConfirmar(r.confirmar);
  }

  function reabrir() {
    void correr("reabrir", () => reabrirElLevante(data.evento.id));
  }

      const reducido = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
      document.getElementById(id)?.scrollIntoView({ behavior: reducido ? "auto" : "smooth", block: "start" });
    };
  }

  const sectores = seccionesDeLevante(data.items);
  const resumen = resumenDeLevante(data.items);

  function pedirTerminar() {
    if (resumen.sinRevisar > 0) setTerminarConfirmar(resumen.sinRevisar);
    else void terminar(0);
  }

  // Si la pantalla se actualizó y la fila de la hoja ya no es la que se abrió
  // (otro teléfono la marcó, cambió el pedido, o se terminó el levante), la hoja
  // se cierra: guardar daría por hecho algo que nadie leyó.
  if (hoja !== null && (!data.puedeMarcar || !data.items.some((i) => sigueComoSeAbrio(hoja, i)))) setHoja(null);

  return (
    <>
      {/* Se actualiza sola: dos personas levantan a la vez con su teléfono. */}
      <RefrescoPeriodico />
      <div className="prep-cabecera">
        <div className="prep-cabecera-fila">
          <Link href="/preparar" className="prep-volver" aria-label="Volver a Preparar">←</Link>
          <div className="prep-titulo">
            <b>{data.evento.lugar}</b>
            <span className="prep-cuando">
              Levante · {data.evento.esHoy ? <span className="prep-hoy">HOY</span> : null} {data.evento.cuando}
            </span>
          </div>
        </div>
        {sectores.length > 1 && (
          <nav className="prep-saltos" aria-label="Ir a un sector">
            {sectores.map((s) => (
              <a
                key={s.category}
                href={`#sector-${s.category}`}
                className={`prep-salto${s.pendientes === 0 ? " ok" : ""}`}
                onClick={saltarA(`sector-${s.category}`)}
              >
                {s.label} {s.marcados}/{s.total}
              </a>
            ))}
          </nav>
        )}
        {error && <div className="form-error prep-error" role="alert">{error.texto}</div>}
      </div>

      <div className="content prep-contenido">
        {data.terminado && (
          <div className="banner ok lev-terminado" role="status">
            <div className="lev-terminado-texto">
              <b>Levante terminado</b>
              <span>{data.terminado.por}</span>
              <span>{textoDeCierre(resumen)}</span>
            </div>
            {data.puedeAjustarStock && (
              <button type="button" className="btn ghost" onClick={reabrir} disabled={enVuelo.has("reabrir")}>
                Reabrir levante
              </button>
            )}
          </div>

        {!data.terminado && !data.puedeMarcar && (

              {data.puedeMarcar && s.pendientes > 0 && esCategoria(s.category) && (
```

```ts
import { prisma } from "./db";
import { validQuantity } from "./quantity";

export type StockInput = { productId: string; newStock: number; expectedStock: number | null; reason: string; note?: string };
export type StockResult = { ok: boolean; error?: string; newStock?: number };

/** `prisma` o el cliente de una transacción: lo que hace falta para mover el stock. */
type DbStock = Pick<typeof prisma, "product" | "stockMovement">;

/** No pisa un recuento hecho después de abrir el formulario. */
export async function saveStock(input: StockInput, userId: string): Promise<StockResult> {
  if (!validQuantity(input.newStock) || (input.expectedStock !== null && !validQuantity(input.expectedStock))) {
    return { ok: false, error: "Ingresá una cantidad entera válida." };
  }
  if (!["ROTURA", "PERDIDA", "COMPRA", "AJUSTE"].includes(input.reason)) return { ok: false, error: "Elegí un motivo válido." };
  if (input.note !== undefined && (typeof input.note !== "string" || input.note.length > 1000)) return { ok: false, error: "La nota puede tener hasta 1000 caracteres." };
  return prisma.$transaction((tx) => moverStock(tx, input, userId));
}

/**
 * El cambio de stock en sí, dentro de una transacción ya abierta: escribe
 * `Product.stock` solo si sigue en `expectedStock`, y deja el movimiento con la
 * diferencia. Es el único camino que escribe el stock: el ajuste de Inventario
 * (`saveStock`) y la baja de lo que no volvió de un evento
 * (`descontarFaltante` en lib/levante-db.ts) pasan por acá, así el historial
 * cuadra siempre con el número.
 *
 * No valida la entrada: eso lo hace quien la arma.
 */
export async function moverStock(tx: DbStock, input: StockInput, userId: string): Promise<StockResult> {
  const product = await tx.product.findUnique({ where: { id: input.productId } });
  if (!product) return { ok: false, error: "Producto no encontrado." };
  if (product.type !== "REUTILIZABLE") return { ok: false, error: "Los consumibles no llevan control de stock." };
  const conflict = { ok: false, error: "El stock cambió mientras editabas. Cerrá este formulario y volvé a abrirlo con el valor actualizado." };
  if (product.stock !== input.expectedStock) return conflict;
  if (product.stock === input.newStock) return { ok: true, newStock: input.newStock };
  const changed = await tx.product.updateMany({ where: { id: product.id, stock: input.expectedStock, type: "REUTILIZABLE" }, data: { stock: input.newStock } });
  if (changed.count !== 1) return conflict;
  await tx.stockMovement.create({ data: {
    productId: product.id, delta: input.newStock - (product.stock ?? 0), reason: input.reason,
    note: input.note?.trim() || null, userId,
  } });
  return { ok: true, newStock: input.newStock };
```

```ts
// ---------------------------------------------------------------------------
// Dar de baja lo que no volvió

/** Si un faltante se puede descontar del stock y, si no, por qué. */
export type Baja = "DESCONTABLE" | "SUELTO" | "NO_LLEVA_STOCK" | "SIN_CONTAR" | "SIN_STOCK";

/**
 * Lo decide el producto como está ahora:
 * - un ítem suelto no tiene producto ni stock: queda anotado y nada más;
 * - un consumible no lleva stock (pudo pasar a consumible después del evento);
 * - un producto que nunca se contó no tiene de dónde descontar: "hay cero" y
 *   "nunca se contó" son cosas distintas (ver `Product.stock`), e inventar un
 *   número sería peor que no descontar;
 * - con el stock ya en 0 no hay nada que bajar.
 */
export function bajaDe(clave: string, producto: { type: string; stock: number | null } | null): Baja {
  if (productoDeClave(clave) === null) return "SUELTO";
  if (!producto || producto.type !== "REUTILIZABLE") return "NO_LLEVA_STOCK";
  if (producto.stock === null) return "SIN_CONTAR";
  if (producto.stock === 0) return "SIN_STOCK";
  return "DESCONTABLE";
}

/** Por qué un faltante no se puede descontar, como lo lee la administradora. */
export const TEXTO_DE_BAJA: Record<Exclude<Baja, "DESCONTABLE">, string> = {
  SUELTO: "Ítem suelto: no lleva stock, queda anotado.",
  NO_LLEVA_STOCK: "No lleva control de stock: queda anotado.",
  SIN_CONTAR: "Nunca se contó en el inventario: contalo antes de descontar.",
  SIN_STOCK: "El stock ya está en 0: no hay nada que descontar.",
};

/** Lo que queda al dar de baja lo que no volvió. Nunca menos de 0: si el evento
 *  llevó más de lo que hay en el depósito (se completó con algo alquilado o
 *  prestado), el stock no puede quedar negativo. */
export function stockDespuesDeBaja(stock: number, faltan: number): number {
  return Math.max(0, stock - faltan);
}

/** La nota del movimiento de stock: "Levante de MUSEO 8/11", con el día del
 *  evento en Argentina. Es lo que se lee en el historial del producto. */
export function notaDeBaja(lugar: string, fecha: Date): string {
  const p = partesDe(fecha);
  return `Levante de ${recortar(lugar, MAX_LUGAR)} ${p.day}/${p.month}`;
}
```

```ts
// ---------------------------------------------------------------------------
// Descontar del stock lo que no volvió
// ---------------------------------------------------------------------------

/** `abierto`: el levante no está terminado (se reabrió). `cambio`: el stock
 *  cambió entre la lectura y la escritura; se puede volver a intentar. El resto
 *  de los motivos son los de `bajaDe`. */
export type ResultadoDescuento = "descontado" | "ya" | "abierto" | "no-existe" | "cambio" | Exclude<Baja, "DESCONTABLE">;

/** Para deshacer la marca de descontado si el stock no se pudo mover. */
class StockCambio extends Error {}

/**
 * Da de baja del stock lo que no volvió de un ítem, una sola vez.
 *
 * Solo en un levante terminado y sobre un ítem que hoy figura como FALTA. La
 * marca del renglón va primero y condicionada (`descontadoAt: null`): de dos
 * toques a la vez, uno solo la pone y uno solo descuenta. El stock se mueve por
 * el mismo camino que el ajuste de Inventario (`moverStock`): mismo control de
 * que nadie lo cambió en el medio, mismo movimiento en el historial. Si ese
 * control falla, se deshace la marca (la transacción entera vuelve atrás).
 */
export async function descontarFaltante(eventId: string, clave: string, motivo: MotivoBaja, actor: Actor): Promise<ResultadoDescuento> {
  try {
    return await prisma.$transaction(async (tx): Promise<ResultadoDescuento> => {
      const ev = await tx.event.findFirst({ where: { id: eventId, ...VIVO }, select: { lugar: true, date: true, levanteAt: true } });
      if (!ev) return "no-existe";
      if (!ev.levanteAt) return "abierto";
      const item = (await levanteDelEvento(eventId, tx)).find((i) => i.clave === clave);
      if (!item || item.estado !== "FALTA") return "no-existe";
      if (item.descontado) return "ya";
      const productId = productoDeClave(clave);
      const producto = productId ? await tx.product.findUnique({ where: { id: productId }, select: { type: true, stock: true } }) : null;
      const baja = bajaDe(clave, producto);
      if (baja !== "DESCONTABLE") return baja;
      // `bajaDe` ya garantizó un producto reutilizable con stock contado y mayor que 0.
      const stock = producto!.stock!;
      const marcada = await tx.levante.updateMany({
        where: { eventId, clave, descontadoAt: null },
        data: { descontadoMotivo: motivo, descontadoAt: new Date(), descontadoPorId: actor.id, descontadoPorName: actor.name },
      });
      if (marcada.count !== 1) return "ya";
      const r = await moverStock(
        tx,
        {
          productId: productId!,
          expectedStock: stock,
          newStock: stockDespuesDeBaja(stock, item.faltan),
          reason: motivo,
          note: notaDeBaja(ev.lugar, ev.date),
        },
        actor.id,
      );
      if (!r.ok) throw new StockCambio();
      return "descontado";
    });
  } catch (e) {
    if (e instanceof StockCambio) return "cambio";
    throw e;
  }
}
```
